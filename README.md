# 🏦 Credit Risk Analysis & Scoring System

This project is a comprehensive, end-to-end data science solution designed to predict credit default risks using machine learning. It reflects my core technical competencies and my strong commitment to building impactful financial technology products.

## 🎯 Project Objective
The primary goal of this project is to automate credit risk assessment. By analyzing historical financial behavior, the system calculates a personalized "Credit Score" and classifies customers into risk segments. This project serves as a practical demonstration of my ability to bridge the gap between complex data modeling and business decision-making.

## 🚀 Why This Project?
I developed this project to showcase my passion for financial analytics and my drive to pursue a professional career in Data Science and Risk Management. It represents my hands-on experience in handling real-world datasets and my dedication to delivering high-quality, actionable insights through advanced modeling techniques.

## 🛠️ Technical Workflow
- **Data Engineering:** Conducted rigorous data cleaning, handled missing values, and treated outliers using Python (Pandas/NumPy).
- **Machine Learning:** Implemented an **XGBoost** classifier, achieving a high-performing **AUC score of 87%+**.
- **Scoring Logic:** Developed a custom scoring algorithm to map model probabilities into a standard 0-1000 credit score scale.
- **Business Intelligence:** Designed an interactive, executive-level dashboard in **Power BI** to visualize risk distributions and model performance.

## 📊 Dashboard Overview
The interactive dashboard provides a 360-degree view of the portfolio's risk profile:
- **Risk Segmentation:** Instant visibility into "Safe" vs "At Risk" customer groups.
- **Feature Importance:** Transparency into the model's decision-making (e.g., Debt Ratio and Utilization impacts).
- **Trend Analysis:** Identifying risk correlations across different age groups and financial metrics.
